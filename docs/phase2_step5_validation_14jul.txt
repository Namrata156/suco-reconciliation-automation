2. HOW SHEETS WERE JOINED
-------------------------------------------------------------------------------

  RRN normalisation: ops stores RRNs as numbers, so leading zeros are lost.
  Each sheet RRN was normalised the way file_processing.tasks._extract_cbs_rrn
  does it: if it is all digits and 8-11 long, zero-pad it to 12 (e.g.
  33078017112 -> 033078017112). On `14`/`Sheet12` the normalised sheet RRN
  equals the system's CBS fact RRN on all 69,239 rows. The only exceptions
  are 2 GL rows where ops' formula gives #VALUE! and the system has no RRN.

  Join keys:
    drc, tmt, adj           RRN -> 14 Jul match group -> current RuleResult
    14, Sheet12, 1535, rev  (Remarks, amount, Withdrawal/Deposit side)
                            multiset-joined to the CBS staging rows of the
                            14 Jul CBS file (cbs_14072026.xls, staging
                            history), then fact -> group -> result
    iss/acq/mer acq/        (RRN, amount, response code) multiset-joined to
    mer iss/Sheet10         the 14 Jul NPCI facts (Raw Data, Merchant Raw
                            Data, BBP; code = staging raw cell 5)
  Ops' "implied outcome" was derived only from ops' own columns (eff/rev,
  REF/EFF, RES CODE). For the NPCI sheets, "in CBS" was taken from ops' own
  `1535` sheet.

  Workbook map (what each sheet is, established from the data):
    1535     the whole 3-day CBS GL 1535 file (13/14/15 Jul), identical to
             the staged CBS file. EFF = lookup of the RRN in 14 Jul NPCI.
    14       14 Jul CBS rows whose RRN appears once that day. REF = the same
             NPCI lookup.
    Sheet12  14 Jul CBS rows whose RRN appears twice (1 debit + 1 credit).
             14 + Sheet12 = all 69,239 14 Jul CBS rows, with no overlap.
    rev      the credit-back leg of every same-RRN CBS pair, per date
             (13/14/15 Jul). Used by drc/tmt's `rev` lookup.
    iss/acq/mer acq/mer iss  the 14 Jul NPCI Raw Data ISS / ACQ, Merchant
             ACQ (+ BBP) / Merchant ISS files, concatenated: DATE (071426),
             RRN, RES CODE, AMT.
    Sheet10  iss + acq + mer acq + mer iss stacked: the lookup target of
             REF/EFF.
    drc/tmt  DRC / Timeout report rows ops acts on, with eff/rev lookups.
    adj      the Adjustment report rows ops acted on.
